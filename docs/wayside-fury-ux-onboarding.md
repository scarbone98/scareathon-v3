# Wayside Fury: opening, HUD and accessibility

New solo adventures enter a six-step practice yard after the skippable story prologue. Players move to a crate, practice three melee hits and a charged strike, dash over a walking barrier, block three telegraphed post swings, blast a distant switch across a fence, and swap partners to open a gate. The course is intended for roughly two minutes of first-time play; there is no imposed minimum time. Skip practice is always available. Completion and skip are distinct saved milestones. An interrupted course restarts from its beginning; completed/skipped courses stay dismissed on Continue. Practice restores the original crew resources and cannot save free practice Ki.

Touch buttons retain the original icons and have visible labels, cooldown overlays and an unavailable cross as well as a gray state. Boost/Brake labels replace Dash/Guard while driving. The adjustable dock keeps targets at least 44 CSS px, with 10 px gaps and safe-area padding. HUD size changes health meters, text and touch controls; Minimal keeps critical vitals/objectives and reduces optional solo HUD elements. Navigation disappears after one second of straight driving, immediately returns on turns, and returns as the vehicle stops. The full map stays available through its keyboard binding.

Settings include HUD/text size, opaque high-contrast dialogs, haptics and solo assists. Extra HP supplies an effective damage buffer (100% extra HP halves incoming damage); canonical crew stats remain unchanged for saves and co-op. Game speed scales solo simulation time. Co-op always runs at normal speed and without the extra HP buffer. Haptics use the browser vibration API when available.

Keyboard bindings include movement, combat, interaction, fusion, map and pause. Duplicate assignments exchange bindings; malformed saved collisions fall back to defaults. Escape remains available for cancellation. The original arrow movement and E swap aliases remain when they do not conflict with a remap. Control legends reflect remaps.

Enemies have role symbols; nearby pickups have type symbols; gates carry their hero symbol/name and locked label in both renderers. Existing original sprites, geometry and collision rules remain in use. Nearby world labels fade by distance. No external art or Buu's Fury assets are used.

Validation: `npm run lint`, `npx tsc -b`, `npm test`, `node scripts/check-wayside-fury-onboarding.mjs`. With Vite running, run `scripts/check-wayside-fury-hud-browser.mjs` and `scripts/check-wayside-fury-ux-browser.mjs` using `FURY_BASE_URL` and, if needed, `FURY_PLAYWRIGHT_MODULE`. The matrix covers phone 2D/3D at DPR 3 and desktop 2D; it intentionally excludes long desktop 3D runs. The added GitHub workflow repeats these checks on the PR.
